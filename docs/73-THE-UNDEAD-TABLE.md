## ⭐ Why this is grouped BY MOD


Ethan, 2026-08-29: *"the idea is we create more tide factions based on difficulty and just theming."*


🔑 **A mod IS a theme.** Each of these rosters was designed by one person to hang together,
so grouping by mod gives coherent factions for free - and a faction drawn from a single
mod will look and sound like it belongs together in a way a hand-picked mix will not.


| mod | the theme it already has |
|---|---|
| **Born in Chaos** | carnival horror - clowns, fishermen, lumberjacks, bonecallers. Hers already |
| **L_Ender's Cataclysm** | norse draugr and the ignited - the heavy end |
| **Ice and Fire** | the DREAD line - thralls, ghouls, the knights of a lich |
| **Goety** | necromancy - ⚠️ most of these RAISE MORE UNDEAD |
| **Occultism** | the Wild Hunt - ⚠️ all twelve are event mobs |
| **Grim & bleak** | folk horror - banshee, templar, ghoul |
| **Vanilla** | the baseline everyone reads instantly |

⚠️ **DIFFICULTY IS NOT IN THIS TABLE AND CANNOT BE SCANNED FOR.** Health, damage and attack
type live in mod code, not in data files. Any difficulty tiering has to be play-tested
or read off each mod's own documentation - it is not derivable from here.
